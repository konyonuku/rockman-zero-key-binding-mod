# Tools

| Tool | Function |
|---|---|
| `arc.py` | Extract and repack MT Framework ARC archives (`extract` / `repack`). |
| `tex_dds.py` | Convert TEX textures to DDS or editable PNG and back (`tex2dds` / `dds2tex` / `tex2png` / `png2tex`). |

Requires Python 3.12 and Pillow. Game assets are not included; extract them from your own install.
